# Conversation Engine Logs

Esta pasta é reservada para logs JSON gerados pelo **Human Conversation Engine**.

## Formato esperado

Os logs gerados pelo botão **Gerar log** no `index.html` podem ser colocados aqui.

## Leitura

O laboratório possui um **Log Reader** que aceita um ou vários arquivos `.json` pelo botão **Ler logs**.

Enquanto o projeto estiver hospedado como GitHub Pages estático, o navegador não lista automaticamente esta pasta. A primeira versão do leitor usa seleção local de arquivos.

Próxima evolução: leitura automática de `logs/` via API/backend, indexação, busca e recuperação de memória histórica.
